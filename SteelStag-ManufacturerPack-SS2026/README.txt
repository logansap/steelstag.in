03-Logo/

  *** STEELSTAG BRAND RULE ***

  1. The APPROVED VISUAL MASTER is SteelStag-Logo-Transparent.png.
     All digital, pouch, hang-tag, label and marketing artwork must
     visually match this master.

  2. No recolouring. No tinting or multiply. No alternate spacing.
     No regenerated stag geometry. If the mark does not read on a
     substrate, change what sits AROUND it - a backing panel, a
     different placement - not the mark.

  3. SteelStag-Logo-Dark.png is the same approved mark on a dark
     ground. Nothing else about it differs.

  4. The .svg / .pdf / .ai files are PRODUCTION DERIVATIVES. They
     carry the same geometry and the same stag-to-wordmark spacing,
     but their metallic treatment is a simplified 25-band rendering
     and does not match the master. Use them where vector is
     genuinely required - cutting, scaling, tooling, single-colour
     work. They must NOT replace the approved visual master in
     full-colour applications.

  APPROVED VISUAL MASTER
    SteelStag-Logo-Transparent.png   <- 1341 x 1342 px, transparent,
                                        80 px clear space all sides
  DARK GROUND
    SteelStag-Logo-Dark.png          <- same mark, same size, on black

  PRODUCTION VECTOR (where vector is genuinely required)
    SteelStag-Logo.ai    <- Adobe Illustrator (PDF container)
    SteelStag-Logo.svg   <- editable vector
    SteelStag-Logo.pdf   <- same vector artwork as PDF

  ADOBE ILLUSTRATOR: SteelStag-Logo.ai  -  SUPPLIED

  A modern Illustrator file is a PDF container, and this is one. It
  opens natively in Adobe Illustrator with all 25 vector paths
  editable, artboard 1005.75 x 911.25 pt. It was built from the same
  approved artwork as the SVG and PDF - no re-tracing, no re-export,
  not one coordinate changed - and verified to render identically to
  the SVG.

  Full disclosure: it does not carry Adobe's proprietary private-data
  stream, because only Illustrator itself can write that. Illustrator
  generates it the first time the file is saved. If your prepress
  specifically requires a CC-native document, open it and re-save once.
  Nothing else is needed, and no artwork changes.

  Use the logo as-is. See the brand rule above.

PRODUCTION BASIS AND APPROVALS

Bulk production for SS2026 is running against this Tech Pack plus the
agreed factory pattern and production reference confirmed directly with
SteelStag. Where the Tech Pack does not state something numerically,
that agreed production reference governs - not a re-interpretation.

The approval sequence in the Tech Pack "Production Workflow" table
remains the process for anything not yet signed off:

1. RFQ             - costing: fabric, CMT, trims, packaging, lead time
2. Lab Dip         - all 5 colours on approved 180 GSM fabric
3. Fit Sample      - 1 pc per style, size M
4. PP Sample       - 1 pc per style x all 5 colours
5. Bulk Production - cut and sew after PP approval only
6. Final Inspection- Final random production QC: random sampling across
                     finished production to AQL 2.5, plus measurement
                     audit and shade check
7. Dispatch        - packing list, invoice, carton details, AWB

NO TOP SUBMISSION REQUIRED. SS2026 does not require top-of-production
samples (previously listed as 2 pcs per style per colour). Quality is
confirmed by final random production QC instead.

Do not move a NEW item to the next stage without written approval from
SteelStag.

Dyeing:      Reactive dyed

             Neck must lie flat - no rolling, no gaping

Hem:         Single needle, 1" hem
Tolerance:   +/-1/4" (0.25") on all measurements
AQL:         2.5

Styles in this order: ST-RN-001 Round Neck, ST-VN-003 V-Neck.

Packaging:   Kraft paper standup zip pouch, 24 x 34 cm
             Manufacturer-standard retail fold to suit that pouch
             Declarations carried on an applied retail sticker

Carton:      Max 100 pcs OR 18 kg gross, whichever comes first
